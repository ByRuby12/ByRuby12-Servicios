# ByRuby12 · Diseño y desarrollo web

Web de presentación de los servicios de Tomás Cano (ByRuby12), con propuestas de diseño y desarrollo para negocios, hostelería y creadores.

## Visita la web

[Abrir ByRuby12](https://byruby12.github.io/ByRuby12-Servicios/)

## Sobre la web

La página reúne un catálogo interactivo de servicios, ejemplos visuales, información sobre el proceso de trabajo, preguntas frecuentes, proyectos de clientes y un formulario de contacto. Se adapta a móviles y ordenadores e incluye búsqueda y filtros para encontrar servicios.

Servicios disponibles:

- Tiendas online y webs profesionales.
- Pack de diseño para creadores.
- Gestión de contactos en Excel y digitalización de negocios.
- Mantenimiento web.
- Carteles, flyers, cartas digitales y publicidad de gran formato.
- Retoque fotográfico.

## Para ejecutar en local

Es una web estática y no requiere instalar dependencias. Desde la carpeta del proyecto, inicia un servidor local:

```bash
python -m http.server
```

Después, abre [http://localhost:8000](http://localhost:8000) en el navegador.

Los archivos principales son `index.html`, `css/styles.css` y `js/app.js`. La carpeta `assets/` contiene imágenes, tipografías y otros recursos de la web.
